# ScamShield sample attribution and license

Dataset: [sidzzz07/scamshield-dataset](https://huggingface.co/datasets/sidzzz07/scamshield-dataset)

Publisher: sidzzz07. Pinned revision: `059dee884476a45e380808e68d09e74baff67291`.

The publisher's dataset card declares MIT. Only `Synthetic_Tier_C`, `is_scam=1` rows from the training split are included here; mixed upstream real-message datasets are not redistributed. This is not Singapore's official government ScamShield service, and the sample is not a collection of verified real incidents.

302 distinct redacted messages are stored in `scamshield_patterns.json`, alongside the separate 36 original TrustGraph examples and 700 additional TrustGraph-authored synthetic variants, for 1,038 catalog messages. The authored variants are NOT ScamShield-origin data. Source IDs, revision, language, synthetic origin, and redaction flags accompany each imported row. The source training file SHA-256 was verified as `418b1d7af29945135284d4293230c75b26c3bccd3dda5382caf730fbc0e49cbf`. Selection digest and category counts are in `scamshield_provenance.json`.

Scanned: 1,004 synthetic scam rows. Removed 702 exact/normalized or number-only variants. All 302 eligible rows are now included; the original 264 records are unchanged. Categories are reused; message count does not equal independent scam mechanisms. Names/locations can still recur. Phone numbers/emails are redacted and common URLs/domains replaced by a reserved `.invalid` address. Do not visit any addresses retained in source text. Text is otherwise retained, not AI-generated by TrustGraph or silently relabeled as real reports.

The requested 1,000 unique ScamShield-origin messages cannot be met from this clean source-authored subset. Validation/test splits contain no additional `Synthetic_Tier_C` scam rows. The user approved supplementation with clearly labeled TrustGraph-authored examples. Mixed-origin source rows are not imported without a separate review of reuse permissions and noisy labels; a message marked as a scam by a dataset is not automatically a verified fraud report.

The original dataset card is preserved in `SCAMSHIELD_DATASET_CARD.md`. No upstream standalone copyright/license file was present in the dataset repository; do not invent an upstream copyright year. Attribution remains with the dataset contributors. The publisher-declared MIT permission terms are reproduced below for the included subset.
